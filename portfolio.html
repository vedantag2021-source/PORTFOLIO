// things I've built

AirChord — play guitar chords with hand gestures

Download build View repo
  • Watches your hand through a webcam and plays the matching guitar chord in real time — five gestures mapped to G, C, D, Em and A.
  • Real-time hand tracking with MediaPipe's HandLandmarker, plus a stability buffer that filters out jitter before a gesture is confirmed.
  • Chord sounds aren't pre-recorded — they're generated from text prompts via ElevenLabs' Sound Generation API, with style and duration customizable from the app's Settings panel.
  • Responsive Tkinter desktop UI with live chord-diagram rendering and a running chord history log.
